Navigation Principles

Every navigation decision should support one of these goals:

Goal	Navigation Support
UX	Experience first, location second, trust later
Conversions	Persistent "Explore Deals" CTA, visible search, minimal top level choices
SEO	Category and destination hubs with scalable URL hierarchy
AEO	Editorial guides, collections, FAQs, structured topical grouping
GEO	City and region navigation supporting nationwide coverage
E,E,A,T	Dedicated About, Partner, Policies, FAQs, Media, and Trust sections
AI Discoverability	Clear semantic hierarchy, descriptive labels, breadcrumbs, and strong internal linking

This structure aligns with the uploaded business description, homepage architecture, keyword strategy, and premium editorial design system while remaining scalable for nationwide expansion.
